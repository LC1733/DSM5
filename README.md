# DSM5

Dashboard clínico de estudio del DSM-5 en un solo archivo HTML: ocho categorías diagnósticas, buscador de trastornos, códigos CIE-10, comparativa DSM-IV/DSM-5, simulador diagnóstico, casos clínicos, diagnóstico diferencial y flashcards.

Material de estudio; no sustituye la evaluación de un profesional de la salud mental ni el texto oficial del manual.

- Sitio: https://lc1733.github.io/DSM5/
- Forma parte del hub **Mente & Decisión**: https://lc1733.github.io/
- Salto directo a un panel: `#cat3` (bipolares), `#quiz`, `#cie`, etc. Los ids son los del menú lateral.
- `catalog.json` describe la app para el hub (convención nivel B).
